# Banking System SQL Project

## Project Overview

This project focuses on analyzing banking data using **SQL**. The database contains information about customers, accounts, transactions, loans, and employees.

The project demonstrates practical SQL skills used for data analysis and banking-related business reporting.

## Database Tables

* **Customers** – Customer details such as name, city, account type, balance, loan amount, and age.
* **Accounts** – Account-related information.
* **Transactions** – Banking transaction records.
* **Loans** – Loan details and customer loan information.
* **Employees** – Employee and manager information.

## Key Analysis

The project includes SQL queries to:

* Analyze customer and account information
* Calculate total and average balances
* Identify customers based on different conditions
* Analyze loan amounts
* Group banking data using aggregate functions
* Combine information from multiple tables using joins
* Identify employees and their managers using self joins
